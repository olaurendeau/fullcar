Les critères

Lecture des couleurs : comme e2e/contrast.ts et rgb() de e2e/ride-remove.spec.ts, une couleur calculée (getComputedStyle, écrite en oklch) est peinte sur un canevas de 1 px et relue en sRGB. Une couleur avec transparence est d’abord composée sur le blanc : peindre #ffffff, puis la couleur, puis lire le pixel. Tolérance : ±1 par canal ; ±0,05 sur un ratio, qui doit aussi rester au-dessus de son seuil.

Décisions

  1. Decision : direction B, pas d’en-tête, marque M1 sur l’accueil et la page introuvable, icônes recolorées, bandeau gris. — Reason : choix du propriétaire sur #651.
  2. Decision : la barre réussie garde #171717 par --inverse. — Reason : l’anneau #737373 à 0 px y garde 3,78:1 ; sur le pétrole, il tomberait sous 3:1.
  3. Decision : --primary à L = 0,42. — Reason : à 0,44, le survol (bg-primary/80) donnait 4,43:1 ; à 0,42, 4,72:1.
  4. Decision : la marque est décorative, sans texte de remplacement. — Reason : le h1 voisin nomme déjà la page ; un nom en plus serait lu deux fois.
  5. Decision : 36 px sur l’accueil, 28 px sur la page introuvable. — Reason : la hauteur de ligne du h1 (36 px) ; et 28 px centré sur la ligne de 32 px du h1 de 24 px.
  6. Decision : l’état vide d’un leg garde l’icône Car de lucide, teintée, pas la marque. — Reason : il parle d’une voiture absente, pas de Fullcar.
  7. Decision : le bloc .dark n’est pas modifié. — Reason : il n’est appliqué nulle part.
  8. Decision : une ligne d’amendement dans les README des maquettes dépassées, sans republier leurs pages. — Reason : une maquette, un artifact ; la ligne suffit à dire qu’une couleur a changé.
  9. Decision : la couleur de l’onglet sélectionné est posée sur le span du nom, d’après props.tab, et non par data-active: sur le déclencheur. — Reason : revue de la v2 ; data-active est en :where() et perd contre hover:text-foreground de tabs.tsx. Une couleur propre au span l’emporte sur tout héritage, sans dépendre de l’ordre des variantes ni modifier tabs.tsx.
  10. Decision : l’entrée 16 px du favicon est recolorée, pas rendue depuis le SVG. — Reason : décision de #103, le 16 px est dessiné à la main pour rester lisible.
  11. Decision : « Partager » passe au pétrole. — Reason : décision du relecteur de la v2 ; c’est ce que fait le code (bouton default) et ce que dessine organizer-view.
  12. Decision : aucun script de production des icônes n’est versionné. — Reason : elles se font une fois ; une étape de build de plus serait à maintenir pour rien.
